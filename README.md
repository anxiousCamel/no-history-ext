# 🛡️ No History

**No History** é uma extensão para Google Chrome elegante e poderosa projetada para proteger sua privacidade automaticamente. Ela monitora seu histórico e apaga instantaneamente qualquer entrada que contenha domínios ou palavras-chave específicas que você definir.

![No History Banner](https://raw.githubusercontent.com/antigravity/no-history/main/assets/banner.png) *(Placeholder para imagem do projeto)*

## ✨ Funcionalidades

- **🗑️ Purge Automático**: Adicione um domínio (ex: `secret.com`) ou uma keyword (ex: `finance`) e a extensão cuidará para que nada disso permaneça no seu histórico.
- **🔐 PIN de Privacidade**: Proteja sua lista de bloqueio com um código PIN. Ninguém poderá ver quais sites você protegeu sem a sua senha.
- **🌍 Internacionalização**: Suporte nativo para **Português, Inglês, Russo, Chinês e Japonês**.
- **🎨 Design Premium**: Interface moderna com efeito *Glassmorphism*, suporte a Dark Mode e animações fluidas.
- **🧹 Varredura Inteligente**: Opção para apagar todo o histórico retroativo ao adicionar um novo site ou fazer uma limpeza completa de todas as keywords de uma só vez.
- **⚙️ Gerenciamento Avançado**: Filtre, ordene e edite suas keywords em uma página de opções dedicada e limpa.

## 🚀 Como usar

1.  **Instalação**: Carregue a pasta do projeto no Chrome via `chrome://extensions/` (Modo Desenvolvedor).
2.  **Adicionar Sites**: Clique no ícone da extensão e digite um site ou clique em "Adicionar site atual".
3.  **Escolher Ação**:
    *   **Apagar Histórico**: Adiciona à lista e limpa o passado.
    *   **Só Adicionar**: Protege de agora em diante sem apagar o que já foi visitado.
4.  **Configurar PIN**: Vá em "Gerenciar" para configurar seu PIN personalizado (O padrão é `1234`).
